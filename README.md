# Published Reader App

This is the child-facing edition generated by an Author app. It contains only the reader, story data, illustrations, narration, quizzes, print view, and PWA shell. It does not include the author dashboard, author lock dialog, PDF importer, image importer, or publishing controls.

Speech synthesis uses the browser's native `SpeechSynthesis` API. No AI service is required. The word-boundary highlight is best-effort because browser speech engines vary.
