# Published Reader App

This is the child-facing edition generated by the Author app. It contains only the reader, story data, illustrations, narration, quizzes, print view, and PWA shell. It does not include the author dashboard, author lock dialog, PDF importer, image importer, or publishing controls.

## Run locally

Serve this folder over localhost or HTTPS:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. `story.json` and its referenced image files should be in this folder.

## Publish

Use the Author app's **Publish Reader App ZIP** button to create a fresh reader package from the current story. The generated ZIP contains `index.html`, `reader.js`, `styles.css`, `story.json`, `manifest.json`, `service-worker.js`, and required image assets.

Speech synthesis uses the browser's native `SpeechSynthesis` API. No AI service is required. The word-boundary highlight is best-effort because browser speech engines vary.
